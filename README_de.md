<a id="introduction"></a>
## 📚 Einführung

Eine Textbibliothek für DTC-Marketer und Kreativteams, die mit physischen Konsumgütern arbeiten. Durchsuche sechs Gestaltungsgruppen, kopiere einen vollständigen englischen Prompt und ergänze die Angaben zu deiner Marke und deinem Produkt. Die Bibliothek bewahrt alle 40 Vorlagentexte vollständig; die Nutzungshinweise stehen separat.

<a id="quick-start"></a>
## ⚡ Schnellstart

1. Wähle im vollständigen Menü unten eine Vorlage passend zu deiner Botschaft und dem gewünschten Layout.
2. Bereite deine Markenidentität, Produktfakten, freigegebenen Werbetexte und die von der Vorlage benötigten Referenzbilder vor.
3. Kopiere den gesamten Prompt und ersetze die Eingaben in eckigen Klammern in einer Arbeitskopie. Prüfe jede sichtbare Aussage anhand deines Kampagnenbriefings.
4. Nutze den ausgefüllten Prompt in einem Bildwerkzeug, das die geforderten Eingaben unterstützt. Stelle das im Prompttext genannte Seitenverhältnis ein und prüfe das Ergebnis.

Die separate Nutzungsanleitung enthält wiederverwendbare Briefings, Anforderungen an Referenzbilder und vorlagenspezifische Ausnahmen. Die Prompts bleiben in allen Sprachfassungen auf Englisch.

[Nutzungsanleitung lesen](docs/usage.md)
