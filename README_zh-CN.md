<a id="introduction"></a>
## 📚 简介

本纯文本模板库面向实体消费品品牌的 DTC 营销人员和创意团队。按六类创意形式浏览，复制完整英文提示词，再填入自己的品牌与产品资料。全部 40 组模板正文完整保留，使用说明独立成文。

<a id="quick-start"></a>
## ⚡ 快速开始

1. 根据想传达的信息和所需版式，从下方完整目录中选择模板。
2. 准备品牌视觉与语气、产品事实、已确认的文案，以及该模板需要的参考图片。
3. 复制整段提示词，在单独的工作副本中填写方括号内的输入项。依据广告简报逐项核对画面中的主张。
4. 将填好的提示词用于支持所需输入的图像工具，按提示词正文设置画幅比例，并检查生成结果。

可复用简报、参考图片要求和模板专属例外，请阅读独立使用指南。所有语言版本中的提示词正文均保留英文。

[阅读使用指南](docs/usage_zh-CN.md)
