<a id="introduction"></a>
## 📚 はじめに

実物の商品を扱うDTCマーケターとクリエイティブチームのためのテキストライブラリです。6つの表現カテゴリーから選び、英語のプロンプトを全文コピーして、自社ブランドと商品の情報を入力します。40のテンプレート本文はすべて保持し、使い方は別のガイドにまとめています。

<a id="quick-start"></a>
## ⚡ クイックスタート

1. 以下の全件メニューから、伝えたい内容と必要なレイアウトに合うテンプレートを選びます。
2. ブランドの基本情報、商品について確認済みの事実、承認済みのコピー、そのテンプレートで必要な参照画像を用意します。
3. プロンプトを全文コピーし、作業用コピーで角括弧内の入力欄を置き換えます。画像に表示する主張はすべてキャンペーンブリーフと照合します。
4. 必要な入力に対応する画像ツールで完成したプロンプトを使います。本文の指示に合わせてアスペクト比を設定し、結果を確認します。

再利用できるブリーフ、参照画像の要件、各テンプレートの例外は、別の使用ガイドをお読みください。どの言語版でもプロンプト本文は英語のままです。

[使用ガイドを読む](docs/usage.md)
