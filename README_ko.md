<a id="introduction"></a>
## 📚 소개

실물 소비재를 다루는 DTC 마케터와 크리에이티브 팀을 위한 텍스트 라이브러리입니다. 여섯 가지 표현 유형을 살펴보고, 영어 프롬프트 전체를 복사한 뒤 브랜드와 제품 정보를 채우세요. 40개 템플릿의 본문을 모두 보존했으며 사용 설명은 별도 문서로 제공합니다.

<a id="quick-start"></a>
## ⚡ 빠른 시작

1. 아래 전체 메뉴에서 전달할 메시지와 필요한 레이아웃에 맞는 템플릿을 선택합니다.
2. 브랜드 정체성, 검증된 제품 정보, 승인된 문구, 해당 템플릿에 필요한 참조 이미지를 준비합니다.
3. 프롬프트 전체를 복사한 뒤 작업용 사본에서 대괄호 입력란을 바꿉니다. 광고에 표시할 모든 주장을 캠페인 브리프와 대조합니다.
4. 필요한 입력을 지원하는 이미지 도구에서 완성한 프롬프트를 사용합니다. 본문의 지시에 맞춰 화면 비율을 설정하고 결과를 검토합니다.

재사용할 수 있는 브리프, 참조 이미지 요건, 템플릿별 예외는 별도 사용 가이드를 읽어보세요. 모든 언어판에서 프롬프트 본문은 영어로 유지됩니다.

[사용 가이드 읽기](docs/usage.md)
