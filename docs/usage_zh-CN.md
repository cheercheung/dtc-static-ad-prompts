# DTC 静态广告模板使用指南

[返回中文模板库](../README_zh-CN.md) · [阅读英文指南](usage.md)

先选择版式，再准备品牌、产品和广告文案资料，最后在自己的工作副本中填写提示词。模板库中的 40 组英文 Prompt 保持原样。模板描述创意形式，不构成产品效果、媒体报道或广告表现的证据。

## 1. 按广告任务选模板

| 广告任务 | 分类 | 需要准备的主要资料 |
|---|---|---|
| 表达主张或优惠 | 信息与优惠 | 标题、辅助文案、真实优惠条款 |
| 呈现用户反馈 | 评价与社会认同 | 真实评价、评分、人数、可使用的身份资料 |
| 解释产品价值 | 卖点与数据 | 已核实的功能、成分、材料、数量与单位 |
| 比较选择或展示变化 | 对比与前后变化 | 可比事实、前后变化的真实记录 |
| 采用原生内容形式 | 编辑内容与原生形式 | 故事、观点、教育内容和对应素材 |
| 在场景中展示产品 | 生活场景与产品展示 | 产品、色款、套装、包装和场景资料 |

分类用于浏览，不表示效果排名。第 20 组原文含音乐场景示例，实际使用时需在工作副本中填写与 DTC 产品相关的场景和故事。第 39 组通过问题画面与标题制造好奇心，不展示产品。

## 2. 准备 Brand DNA

网站里明确出现的事实，与根据视觉观察提出的设计建议，要分开记录。估计的色号不是已确认的品牌规范。无法读取网站时，改用人工填写表单；资料仍需品牌方复核。

```
品牌名称：
目标人群与定位：
品牌语气（五个具体形容词）：
已确认的品牌文案示例：
主色／辅助色／强调色／背景色及色号：
哪些颜色已确认，哪些是待审设计建议：
标题与正文字体风格：
摄影：光线、取景、场景、台面与色调：
产品包装与标签的识别特征：
必须出现的视觉元素：
需要避免的视觉元素：
```

## 3. 准备 Product DNA

以产品页、包装或可查证的产品资料为依据。在私人工作简报中记录事实的依据。未知项留空并补充资料，不把推断或未经审核的生成内容当成产品事实。

```
产品名称与品类：
外形、材料、标签与包装：
尺寸／口味／颜色／款式：
已确认的产品介绍与标语：
已核实的卖点：
成分／材料：
已确认不含的成分：
真实数值、单位与依据：
比较对象及比较依据：
可用的产品参考图：
```

## 4. 先确认完整广告简报

为每个选中的模板，列出受众会在图上读到的全部文案。Brand DNA 决定语气，Product DNA 提供事实。依照模板约定控制字数、行数和标注数量，确认后再填提示词。

```
模板编号与标题：
广告目的与目标人群：
标题／副标题：
优惠、价格、日期与真实条款：
卖点／成分／材料：
统计数据与单位：
评价原文、姓名、评分与数量（如需要）：
媒体引语与媒体身份（如需要）：
比较双方的优势与不足（如需要）：
场景、人物与所需参考素材：
模板正文要求的画幅比例：
仍需补充的输入：
已确认的全部广告文案：
```

缺少评价、评分、用户人数、客户姓名、媒体报道或竞争产品事实时，应请求真实材料。加上警示符号也不能把编造的数字变成事实。评价卡片、评论和新闻界面是视觉形式，不可将模拟界面或虚构内容当成真实背书。概念稿采用虚构内容时，应在该概念稿中明确其性质。

## 5. 填写独立工作副本

复制完整 Prompt，替换其中的方括号输入，也要检查标题内部的嵌套输入。`like` 或 `e.g.` 后的文字只是填槽示例，不是其他品牌可以直接继承的事实。

明确颜色、对比度和字体：浅底深字，深底浅字，并保持品牌语气与包装识别特征一致。仅使用简报已确认的事实，不在填词阶段增加未经确认的数值。提示词无法保证模型准确还原商标、标签、人物或产品，生成后仍需检查。

## 6. 按模板准备参考素材

产品出镜时，可准备清晰、光线良好、标签可读的产品图；品牌参考图用于辅助颜色和风格。多色款、套装或人物需要足够的实际资料，一张单品照不能说明整个系列。

| 模板 | 使用条件或例外 |
|---|---|
| 11 | 正文允许 1:1 或 3:4；工作副本和图像工具中应选定一种。 |
| 12 | 展示三个配色，需要真实款式的参考图或已确认描述。 |
| 14 | 保留多商品、开盒套装结构，提供实际套装与包装资料。 |
| 20 | 明确不展示产品实拍；不要强制把参考产品塞入画面。 |
| 29 | 不展示产品、品牌标识或 CTA，重点是人物与观点帖子。 |
| 39 | 不展示产品、标识、品牌或 CTA，重点是问题画面与钩子。 |

不要统一加上“所有广告必须展示参考产品”的指令，这会与第 20、29、39 组冲突。第 14 组不适用统一单品规则。第 18 组是生活场景平铺的环绕数据形式，对应的产品主视觉形式是第 13 组。

## 7. 采用正文画幅比例

分类页标注的比例取自各模板正文末尾，不采用可能有差异的菜单标签。第 34 组中的 `10:45` 和 `10:44` 是界面时间，其画幅是 1:1。

选择支持所需参考输入和画幅的图像工具；工具比例设置与工作 Prompt 保持一致。每次生成后先审核，再决定重试或调整。现有示例图仅展示对应模板的创意形式，不构成模型效果比较。

## 8. 审核生成结果

对照已确认的简报，检查画面文字、产品外形与标签、款式数量、场景、版式、对比度、画幅和事实主张；检查评价、人物、媒体或社交界面是否暗示了不存在的证据。使用前修正不实内容。

将简报、填写后的 Prompt、参考素材和选定成图保存在自己的广告工作目录。评估广告效果时只采用实际观察到的结果；拥有一个模板不等于已取得效果。
