<a id="introduction"></a>
## 📚 Введение

Текстовая библиотека для DTC-маркетологов и творческих команд, работающих с физическими потребительскими товарами. Выберите один из шести типов креативов, скопируйте полный промпт на английском и подставьте данные своего бренда и продукта. Все 40 текстов шаблонов сохранены; инструкции по использованию вынесены в отдельное руководство.

<a id="quick-start"></a>
## ⚡ Быстрый старт

1. Выберите шаблон с нужным сообщением и композицией в полном меню ниже.
2. Подготовьте описание бренда, проверенные сведения о продукте, согласованный текст и референсы, необходимые для этого шаблона.
3. Скопируйте промпт целиком и замените поля в квадратных скобках в рабочей копии. Сверьте каждое утверждение, видимое в рекламе, с брифом кампании.
4. Используйте заполненный промпт в инструменте создания изображений, поддерживающем нужные входные данные. Задайте соотношение сторон из текста промпта и проверьте результат.

Формы брифов, требования к референсам и исключения для отдельных шаблонов приведены в отдельном руководстве. Во всех языковых версиях тексты промптов остаются на английском.

[Прочитать руководство по использованию](docs/usage.md)
