<a id="introduction"></a>
## 📚 Introduction

A text library for DTC marketers and creative teams working with physical consumer products. Browse six creative families, copy a complete English prompt, and fill it with your own brand and product details. The library preserves all 40 template bodies; usage guidance is kept separately.

<a id="quick-start"></a>
## ⚡ Quick Start

1. Choose a template by the message and layout you need from the complete menu below.
2. Prepare your brand identity, product facts, approved copy, and any reference images required by that template.
3. Copy the entire prompt and replace its bracketed inputs in a working copy. Check every visible claim against your campaign brief.
4. Use the filled prompt in an image tool that supports the requested inputs. Set the aspect ratio from the prompt body and review the result.

Read the separate usage guide for reusable briefs, image-reference requirements, and template-specific exceptions. Prompts stay in English in every language edition.

[Read the usage guide](docs/usage.md)
