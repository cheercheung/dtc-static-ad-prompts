<a id="introduction"></a>
## 📚 Présentation

Une bibliothèque de textes pour les spécialistes du marketing DTC et les équipes créatives travaillant sur des produits physiques de consommation. Parcourez six familles créatives, copiez un prompt complet en anglais et renseignez les détails de votre marque et de votre produit. La bibliothèque conserve intégralement les 40 modèles ; les conseils d’utilisation sont présentés séparément.

<a id="quick-start"></a>
## ⚡ Démarrage rapide

1. Choisissez un modèle dans le menu complet ci-dessous selon le message et la composition souhaités.
2. Préparez l’identité de marque, les données factuelles du produit, les textes approuvés et les images de référence demandées par le modèle.
3. Copiez le prompt entier et remplacez les champs entre crochets dans une copie de travail. Vérifiez chaque affirmation visible à l’aide de votre brief de campagne.
4. Utilisez le prompt rempli dans un outil d’images acceptant les éléments demandés. Réglez le format d’image indiqué dans le corps du prompt et examinez le résultat.

Consultez le guide d’utilisation séparé pour les briefs réutilisables, les exigences concernant les images de référence et les exceptions propres aux modèles. Les prompts restent en anglais dans toutes les versions linguistiques.

[Lire le guide d’utilisation](docs/usage.md)
