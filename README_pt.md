<a id="introduction"></a>
## 📚 Introdução

Uma biblioteca de textos para profissionais de marketing DTC e equipes criativas que trabalham com produtos físicos de consumo. Explore seis famílias criativas, copie um prompt completo em inglês e preencha-o com os detalhes da sua marca e do seu produto. A biblioteca preserva o texto integral dos 40 modelos; as orientações de uso ficam separadas.

<a id="quick-start"></a>
## ⚡ Início rápido

1. Escolha um modelo no menu completo abaixo conforme a mensagem e a composição de que você precisa.
2. Prepare a identidade da marca, os dados do produto, os textos aprovados e as imagens de referência exigidas pelo modelo.
3. Copie o prompt inteiro e substitua os campos entre colchetes em uma cópia de trabalho. Confira cada afirmação visível com o briefing da campanha.
4. Use o prompt preenchido em uma ferramenta de imagens compatível com os materiais solicitados. Defina a proporção indicada no corpo do prompt e revise o resultado.

Consulte o guia de uso separado para encontrar briefings reutilizáveis, requisitos de imagens de referência e exceções de cada modelo. Os prompts permanecem em inglês em todas as versões de idioma.
